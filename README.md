\# Gerador de QR Code



Um aplicativo desktop simples e eficiente construído com Python e PyQt6 para gerar QR Codes instantaneamente. O aplicativo renderiza o QR Code diretamente na memória RAM, sem necessidade de salvar arquivos temporários no disco.



\## Requisitos



\- Python 3.10 ou superior

1\. Clone ou baixe este repositório.

2\. Abra o terminal na pasta do projeto.
